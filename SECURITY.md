# Security Policy

## Supported Versions

Only the latest release of Mack receives security fixes. Updates ship
through the in-app updater and https://mack.sh.

## Reporting a Vulnerability

Please use GitHub private vulnerability reporting:
https://github.com/ifubaraboye/mack/security/advisories/new

If that doesn't work for you, email hi@egoist.dev.

Please don't open a public issue for anything you believe is
exploitable before it has been fixed. Include reproduction steps and
the Mack version (Mack → About Mack) you tested.
